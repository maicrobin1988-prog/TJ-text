# 项目前期研究与概念策划

独立技能 `interior-project-research`：从项目名称、任务书、聊天摘录、图纸、照片或链接启动室内项目前期研究，形成项目认知、当前关键判断、策略解法和概念策划汇报结构，默认用飞书画板组织原生逻辑节点与真实资料截图。

## 安装

在支持技能安装的 Codex 中发送：

```text
请用 $skill-installer 安装这个 skill：
https://github.com/maicrobin1988-prog/TJ-text/tree/main/skills/interior-project-research
```

也可克隆仓库，将完整的 `skills/interior-project-research` 目录复制到项目的 `.agents/skills/`，或个人的 `~/.codex/skills/`。已有同名技能时先备份，再更新；不要把仓库根目录的 `tj-text` 当作本技能安装。安装后在下一轮调用 `$interior-project-research`。

其他支持 `SKILL.md` 的 Agent，可按平台方式导入该目录，以 `SKILL.md` 为入口。本技能本身没有 Python、Node.js 或 Draw.io 的必装运行依赖，也不需要安装仓库根目录中用于 TJ-text 演示文稿的 Python 依赖。

## 使用

```text
用 $interior-project-research 调研「项目名称」。
已知：地点、业主或项目类型（知道多少提供多少）。
附件：任务书、会议摘录、图纸、现场照片或相关链接。
请给出当前最需要关注的问题、策略与解决方向、概念策划汇报结构，
并以飞书画板呈现推导逻辑和证据截图。
```

只有项目名称也可启动。同名对象无法辨认时，先利用已有线索辨认，再仅澄清影响后续研究的必要信息，不补造业主、地点或项目条件。

## 工作流程与成果

1. 十维扫描项目缘起、业主发展、决策利益、行业外部、城市地域、建筑场地、人群活动、竞对标杆、投资运营和实施条件。
2. 跨维识别差距、矛盾与机会，判断当前优先事项及其依据；十个维度不机械对应十条策略。
3. 推导项目主张、概念原则、策略，以及空间或流程层面的具体动作、成立条件和验证方式。
4. 按汇报论证组织前端篇章，给出每章主结论、依据、图示与承接，章节及页数随项目调整。
5. 用画板分区呈现研究、判断、解法、汇报与待核任务；原页证据紧邻判断，区分事实、各方表述、外部观点与研究推断。

资料缺失时继续推进可以独立完成的研究，同时标明缺口。方案效果图、设计目标和投入使用后的成效分别表述。

## 运行能力与飞书交付

执行研究的 Agent 需要具备网页检索和所提供附件的读取能力；文件解析、图像与图表制作由调用环境提供，本技能不捆绑工具服务。

飞书云端交付需要调用者自己的账号、可用的连接器/CLI或已登录网页，以及目标文档和画板的读取、编辑、图片上传授权。`lark-doc`、`lark-whiteboard` 等操作技能不随本目录附带，已安装时可按需使用对应说明。

未配置飞书时，可先交付本地可编辑图稿及证据素材，明确标记“云端未完成”。Draw.io 仅为可选的导入路径。不得把本地文件、空白画板或未重开验证的链接称为已完成的飞书交付。

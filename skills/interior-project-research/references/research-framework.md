# 研究维度与证据

## 用碎片资料启动

先建立轻量的项目事实卡：项目名称与别称、业主及使用主体、位置与类型、阶段、规模口径、启动缘由、当前目标、资料来源/版本。只填有依据的信息。先读已有任务书与项目材料，再补外部研究，避免将已经给出的答案反复询问用户。

只有名称时，先查主体与项目身份、公开启动背景、地区与行业条件；内部使用需求保持未知。任务书较完整时，重点找隐含目标、约束、冲突和遗漏，不重复抄写。延续研究时沿用已确认事实和证据编号，标注新增、修正及仍待核实的判断。

## 十维扫描

每维先判断相关程度、已有证据与缺口，再安排研究深度。十维是覆盖视野的索引，不是固定报告章节或十个独立答案。

| 维度 | 核心研究问题 | 有用的资料与判断输出 |
|---|---|---|
| 项目特质与缘起 | 为什么现在启动？新建、改造、搬迁或升级？已处在哪个阶段？ | 任务书、启动节点、既往方案、项目沿革；区分表面委托与真实任务，形成阶段判断 |
| 业主背景与发展 | 主体性质、业务/职能、发展阶段、品牌定位、近期动作、组织文化是什么？ | 官方资料、公开报告、既有空间及客户材料；解释项目在其发展中的作用，区分公开叙述和内部真实诉求 |
| 决策与利益关系 | 谁出资、持有、使用、运营、审批和拍板？如何定义成功？ | 项目组织与会议、访谈、采购文件；画出角色和目标关系，未知关系不推定 |
| 行业与外部环境 | 客户所在领域及相关空间类型发生什么变化？哪些技术、市场或政策变化影响本案？ | 行业研究、原始数据、官方信息与机构方法；分开业务趋势与设计趋势，说明本项目相关性 |
| 城市区位与地域 | 城市、片区、周边产业与人群、交通、文化、气候和自然条件意味着什么？ | 规划与地方原始资料、地图、现场信息；识别资源和边界，地域事实不直接等同于设计符号 |
| 建筑与场地 | 空间、结构、设备、采光、通达性、既有问题及更新潜力如何？ | 已有图纸、现场记录、物业资料；识别影响方案成立的条件，实测与图像推断分开 |
| 人群活动与需求 | 谁在何时做什么？如何到达、停留、工作、交流、恢复或离开？ | 访谈、活动记录、现场观察、现状反馈；形成分人群需求与关键场景，需求未核实时不伪造行为数据 |
| 竞争与参照案例 | 业务同行如何发展？同类项目如何配置？设计标杆怎样解决相似问题？ | 企业原始资料、项目原册、设计机构案例、必要的专业媒体；分别比较，提炼机制、条件与局限 |
| 投资运营与长期价值 | 投入目的、资源边界、运营维护能力、使用周期及未来变化是什么？ | 客户预算口径、运营要求、维护资料；提出投入优先和适应性方向，市场报价与确认预算分开 |
| 实施与协作条件 | 时间、服务范围、标准成熟度、采购方式、团队与外部依赖是什么？ | 合同范围、招标澄清、计划及标准文件；识别先决条件、分期与接口，不自动扩成正式报价或工程深化 |

按业态改变研究侧重。例如办公研发关注协作、专注、保密和访客关系；零售关注渠道、购买任务、展示服务和标准化；私宅关注家庭阶段、生活行为、舒适与维护；交通/公共文化项目关注公共服务、使用峰值、可达性和地域语境。此处是研究提示，不是预设结论。

## 检索与核验

先列当前要核实的对象和问题，再选择来源。优先利用用户提供的任务书、会议、图纸、现场资料及已授权案例库；按问题补充业主官方文件、政府和原始研究、设计机构原案、专业媒体。社交平台可发现线索，重要主张尽量回到原作者与原件。GitHub 用于需要开源方法或工具的专题，不要求每个项目都检索。

对同一来源不要机械赋予统一可信度。例如官网可核对业务与公开动作，但不能替代员工访谈；设计机构案例可证明提出了何种方案，但不能单凭效果图证明投入使用后的成效。涉及现行法规、标准和价格时按所在地、用途及日期核验，列明适用范围，不把零散搜索摘要当确定条件。

资料记录的最低内容：证据编号、对象/维度、原文或可见事实、来源链接/文件、发布日期或资料日期、访问日期、物理页码/位置、图像类型、状态与适用范围。来源未给日期时写未载，不借用网页抓取日期冒充发布日期。

证据状态可区分：

- **事实**：原件、数据或现场记录支持的有限陈述，保留范围。
- **各方表述**：业主、使用者、运营方等提出的诉求和主张，标注角色、时间。
- **外部观点**：机构研究、趋势预测、同行自述，交代样本与适用条件。
- **研究推断**：由哪些证据得出，对本项目意味着什么，哪些条件尚待验证。

图纸、任务书、会议和现场不一致时列出冲突及决策影响。多个转载同一原文不能算多个独立证据。面积、人数、比例和预算比较必须有相同口径、范围与分母，证据不足留空。

## 从广度研究到优先判断

先将发现归并为目标—现状差距、主体诉求冲突、资源约束和组合机会，辨别根因与症状。不要因某维资料多就认定它最重要。

用以下问题作综合判断，不强制量化评分：

1. 是否影响项目的主要目标、关键人群或方案成立？
2. 是否必须在本阶段决定？晚处理会造成什么锁定或返工？
3. 是否连接多个现象，属于更根本的矛盾？
4. 本轮能采取哪些行动，设计能影响到哪里？
5. 依据是否充分？最可能改变判断的缺口是什么？

形成一段清楚的当前判断：

> 本项目当下最需要关注……；依据为……；如果不回应，可能……；因此本轮优先……；该判断仍取决于……。

按实际情况安排本轮必须回应、重要且需并行核实、后续推进。各类数量随项目变化；“重要但未知”要转成核实任务，不用虚构结论填满。

具体核实任务写清核实对象、需要哪种资料或观察、影响哪项判断。例如要求确认访客进入范围，以决定展示流线与保密工作区的关系，比泛泛写“进一步了解需求”更可行动。

## 按需查阅的方法参照

- [RIBA Plan of Work 2020](https://www.riba.org/media/sszn5kkt/2020ribaplanofworktemplatepdf.pdf)：借鉴战略目标、项目理由、可行路径与具体任务书的区分，不当作所有地区项目的规定流程。
- [Gensler Workplace Performance Index](https://www.gensler.com/workplace-performance-index)：办公专题可借鉴调查—比较—设计建议—使用后测量的逻辑，不声称已接入或复刻其专有评分体系。
- [HKS Design Intent 方法介绍](https://www.hksinc.com/our-news/articles/how-is-design-excellence-shaping-the-future-of-health-care/)：借鉴记录设计理由、指导原则和效果验证的对应关系。

这些来源解释方法，不证明本项目的诉求或设计效果；不要求每次研究都重新读取。

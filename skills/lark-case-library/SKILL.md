# 飞书案例解剖与归档

每案交付一个可阅读、可搜索的飞书画板和一条多维表格记录。画板负责拆解与图像证据，记录负责检索、画板链接和原始 PDF 附件。导图结构直接放进画板，独立思维导图及「解剖导图链接」已退出流程。

## 执行顺序

1. **定位案例与目标。** 确认 PDF 版本、物理页数、项目类型、来源标注的作者或设计品牌、文本所处阶段。确认用户指定的飞书多维表格、数据表或单条记录，先查已有案例与字段。没有明确的归档位置时，可先做拆解，再请用户指定目标。仅要求查阅旧案例时走只读路径。
2. **先拆结构，再选证据。** 通过目录、章节页和全册缩览定位叙事，然后阅读关键原页。用六个分支保留完整结构：案例定位、汇报叙事、概念推导、策略剖析、品牌表达、复用提纲。每项关键策略都写明来源页、设计动作、优点、局限和可迁移条件。详见 [案例拆解与图版](references/case-breakdown.md)。
3. **制作画板。** 将六个分支和子节点写成画板内可搜索的文字或图形节点，再用分区承载关键图版。每组以完整原页和带页码的局部解释空间决策，可按需要加入构件、动线、材质、灯光和取样色。把策略判断、页码及复用条件另写成可搜索的画板文字。
4. **归档至同一条记录。** 先确认目标字段与重复项，写入分类、摘要及画板超链接，把原始 PDF 上传到附件字段。同案深化沿用原记录及画板入口，更新版本。工具选择、字段映射、重试与权限处理见 [飞书归档](references/feishu-archive.md)。
5. **重开并验证。** 从单条记录重新打开画板和 PDF，核对案例身份、版本、附件页数与选定的原页。抽查一项可搜索策略能找到对应图版，并从图版的物理页码回到原 PDF。区分实际打开 PDF 与仅看附件入口，区分已完成和待补步骤。交付单条记录链接，可附画板直达链接。

## 引用与复用

从案例记录进入画板，先读策略、应用条件和证据边界，再从附件核对原页。输出使用「案例名或案例 ID＋PDF 物理 P 页＋案例记录链接」，解释可借鉴的设计动作、本项目差异及待核输入。使用原作者归属。将原页所示、分析推断、实际落地情况分开陈述；找不到原件时标明引用来自画板及核验状态。

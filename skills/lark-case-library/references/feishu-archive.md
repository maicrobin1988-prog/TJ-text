# 飞书归档

## 定位和字段

使用调用者指定或已配置的案例库。先读目标数据表的真实字段、类型、记录和权限，再按语义映射。遇到名称不同但语义和类型相同的字段可复用。缺字段或类型不符时，说明差异并在已授权范围内调整，避免为单次任务重构现有表。

| 信息 | 字段建议 | 写入要求 |
| --- | --- | --- |
| 案例名称、案例 ID | 文本 | 名称可读，ID 按现库规则唯一 |
| 项目类型 | 单选或现有分类 | 沿用既有选项，如总部办公、普通办公、酒店、商业 |
| 设计品牌、阶段、版本 | 文本或现有选项 | 作者按原资料标注，记录版本可与原件版次分开 |
| 策略标签及摘要 | 多选或文本 | 摘要可含叙事、核心策略、优缺点和复用条件，随实际字段写入 |
| 画板样板／案例画板 | 超链接 | 指向能直接阅读的正式画板 |
| 原始PDF | 附件 | 上传原始 PDF 文件，核对文件名、页数和版本 |

按单条记录链接或案例 ID 优先匹配，再用项目名、阶段和版本消歧。页数或文件名只是辅助线索，必要时用文件哈希识别完全相同的文件。同案迭代复用原记录和画板。新增案例按库内规则分配未用编号，写前再次检查 ID，遇到名称冲突或已有不同来源版本时不要覆盖其他记录或附件。

## 创建、更新与恢复

- 优先用可用的飞书连接器或 CLI，按需调用画板、云盘附件和多维表格能力。若有相应技能，查阅 `lark-whiteboard`、`lark-base` 和 `lark-drive`。缺某项能力时，可用已授权的飞书浏览器界面完成该步骤。访问权限以各人的飞书身份为准，不在发布包中预置租户、链接或凭证。
- 按当前界面提供的可编辑方式创建完整结构，例如原生节点，或导入层级图后验证节点能搜索。插入原页图版、页码文字和评析。编辑旧画板时确认目标，保留有用内容和有效入口。
- 更新原件版本前，先核对记录、画板和附件的写入能力。准备好新版图版，先上传并回读新版 PDF，再更新正式画板和记录版本；保留或替换旧附件按案例库规则和用户授权执行。若新版附件无法写入，保留当前已核验版本，另交新版拆解草稿。
- 把画板链接与原始 PDF 写入同一记录。若途中失败，回查云端已创建的画板、记录和附件，再从缺失步骤续做。上传大小、权限或网络有实际限制时，交付已完成的本地材料并列明待写入项。不要用压缩过的图版替代原始附件。
- 保存后从记录链接重新进入。核对目标案例、画板标题、文件名和附件版本，打开 PDF 预览核页数及至少一处页码。打开画板查看完整结构和选定的证据组。只有链接或缩略图可见时，记录为入口可见。

团队成员或策划 Agent 从同一条案例记录链接进入。引用时交代原页、设计动作和复用条件；需要访问同一个飞书案例库的已有权限。安装此技能和获得案例访问权限是两个独立步骤。

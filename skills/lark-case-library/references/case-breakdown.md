# 案例拆解与图版

## 把汇报逻辑和空间设计分开看

| 导图分支 | 写入内容 |
| --- | --- |
| 案例定位 | 类型、规模或阶段、版本与作者。只写资料能支持的事实。 |
| 汇报叙事 | 还原原册的章节顺序、每章要回答的问题、页段和章节之间如何推进。 |
| 概念推导 | 追溯业务、用户或文化依据如何形成主张，主张又如何落到楼层、动线、场景和构件。 |
| 策略剖析 | 按场景或决策拆解。写清楚服务谁、在哪发生、做了什么、证据在哪。记录各策略的优点和局限。 |
| 品牌表达 | 识别访客、员工等人群在什么触点接触品牌，形态、材料、灯光、色彩和艺术如何协同，哪些可以形成系列。 |
| 复用提纲 | 把可借鉴动作写成可执行方法，给出输入条件、需要比较的指标、适用边界及实施前核验项。 |

为同一案例选择能解释关键决策的证据组，通常 3–6 组。可按项目需要增减。优先把原型与转译、平面与效果、方案 A/B、同空间不同模式或构件与材料表并排。画板先给叙事索引，再放完整结构和证据分区，避免在一个全览里堆叠不可辨认的小字。

## 图版证据格式

1. 标明案例、证据主题和 PDF 物理页码。封面计 P1，若印刷页脚不同，可同时标注但不混用。保留完整原页缩略图的画幅和页码，让局部有可追溯的出处。
2. 裁取能说明设计动作的区域，保留原图比例与颜色。用短标记指出构件、位置和使用情境，例如端景在入口视轴、座椅在短停区、灯具为导向或分场控制。只在有证据时认定具体材料或规格。
3. 配色有解释力时，从明确页码和部位取样，标出色块、色值与角色，如基底、强调、引导。色值是原页屏幕采样，实物定色看样板。流程、平面或文字证据可省略配色。
4. 图旁写可搜索的短评：原页显示什么、优点、局限、怎样复用、复用前验证什么。标清方案效果、白模、外部意向、实景、概算或工程依据。方案表达只能证明提案意图，概算按原文注明计价范围。
5. 导入后重开画板。检查总览分区、放大后的原图和文字、裁切与遮挡，搜索一项策略或页码。图片清楚优先；若上传通道限制文件大小，适当压缩或拆组，并复核关键图例和字仍可辨认。

## 虚构示例

「河湾总部」（虚构）P8 平面标出访客签到后可去展廊，员工刷卡后直达电梯。P9 的同视角方案图用线灯延续展廊方向，以暖木包覆等候座。优点是通行方向与等候边界在空间中可辨；局限是 P8–9 没有排队峰值和夜间运营数据。复用前先给出访客与员工峰值、门禁位置、排队缓冲及无障碍路径，再比较导向、眩光和维护条件。

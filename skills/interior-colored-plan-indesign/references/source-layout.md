# 通用 A3 彩平页式

正式页使用原生 A3 横向 420 × 297 mm，非对页。左侧为当前项目的彩平主图，右侧为编号与功能名称清单，标题与页脚保留清晰层级。可用 [原生空白模板](../assets/templates/A3彩平版式模板.indt) 或 [IDML 交换模板](../assets/templates/A3彩平版式模板.idml)；跨版本优先使用 IDML。

## 几何与阅读关系

- 建议左右安全边距 15–18 mm；主图占约四分之三内容宽度，图例占约四分之一。长条形、复杂或密集平面按实际比例调整，不拉伸建筑以填满框。
- 地坪材质、原始 PDF、墙体家具强化、阴影、编号和版式分层。锁定 PDF 是可追溯底图；置入它不会把内部线条或文字转成原生可编辑对象。
- 图内圆形编号、数字及右侧名称保持原生编辑。图内编号与图例来自同一份空间清单，每号只有一个功能归属。
- 名称较长时在固定列宽中自动增高换行，不能横向撑出页面。条目过多可用双列图例，或按楼层/分区增加 A3 页；主图与对应功能表仍应同页可对照。
- 主次空间可用编号色深浅区分；色彩不能代替编号。英文仅采用已有或用户要求的译名。

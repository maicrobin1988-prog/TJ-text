# 室内彩平制作

在 **Adobe InDesign** 内完成彩平与 A3 版式，保留原始平面及新绘内容的可编辑边界。用户说“彩屏”时按室内彩平理解。以用户本轮 PDF、图面文字和最新补充为功能与几何依据；参考案例负责表达风格，不提供本项目的房间、家具或尺寸。

## 默认机制：先选预存风格，选后直接制作

**首轮只做选样。** 收到新 PDF 后，检查文件可访问即可，立即展示 [八款风格速选图](assets/style-picker/八款风格速选.png) 并给出样式选项。它来自五类八款的自造固定简图，不是当前项目的小样。选样前不运行完整 PDF 检查/OCR、不逐间识读或描图、不启动 InDesign，也不调用生成工具重新做这些简图；节约工作量和 token。

读取 [scripts/show_style_options.py](scripts/show_style_options.py) 的输出即可获得当前安装位置下的图片绝对路径、八个样式 ID 和选择卡参数：

```bash
python3 /absolute/skill/scripts/show_style_options.py
```

首个选样结果同时包含预存图和选择入口：

- 使用宿主的图片预览或附件显示速选图；支持本地 Markdown 图片的工具可直接使用脚本返回的 `preview_markdown`。优先使用宿主已有的单选工具，问题与选项见 `question` / `choices`；Codex 可使用可用的 `request_user_input_async` 及同名参数字段。没有单选工具时直接列出 ID，让用户回复编号。图片不能内联时用附件/文件预览，不重画图片。普通对话不需要另建网站或打开浏览器。
- 默认一次列出 **A1、B1、B2、B3、C1、D1、D2、E1**，选具体款式后直接制作，避免多一轮父类选择。用户只回复 B 或 D 时，才显示对应预存分组图并请其选择子款：`show_style_options.py --group B` 或 `--group D`。
- 没收到实际选择就等待，停止与该 PDF 有关的制作工作。界面预选、推荐、用户打开图片或沉默均不是选择。收到回复后记录样式 ID、用户原意及配色调整，不再要求重复确认。
- 用户已明确指定样式、指定沿用本项目已选风格，或一次选择适用于同批多份 PDF 时，直接复用这个选择；不逐页、逐文件重复弹出。用户提供明确的新风格参考时，以其指示为准。

仅当用户**明确要求把几种风格制作到当前 PDF 上比较**时，才做项目多款 demo；“测试一下彩平”“看有哪些风格”仍先展示预存选项。缓存缺失时报告具体缺项，不改用新项目多款制作替代。图库重建仅用于用户要求更新图库或修复缺失资源，见制作参考。

## 选定后的单款制作

1. **核对这份底图。** 使用 [inspect_pdf.py](scripts/inspect_pdf.py) 获取页码、旋转/裁剪、可复制文字及预览，再看图核对。已有同版本核图结果可复用。扫描或轮廓文字需视觉识读/OCR；路径数量、文字提取成功不等于房间已识别。
2. **建立功能清单和几何。** 记录空间的 `id / name / anchor / source_label / status`；同名不同房间分别编号，源图已有编号优先保留。按真实边界描地坪、门洞、墙线和材质分界，不凭家具猜房名或改变布局。未知信息标明，不虚填比例和面积。
3. **只制作已选款式。** 这时才读所选款的 [风格参数与参考](references/style-catalog.md)、[原生版式依据](references/source-layout.md)，执行下文原生制作与验收。直接交付用户要求的单款成果，不再先交一轮项目 demo 重新选样。常规材质未定可以作为表达示意，不把可注明的假设变成重复问卷；只有真正阻塞制作的关键信息才需澄清。

## 选择后精细制作

在 InDesign 中保留锁定 PDF 底图，原生制作地坪边界/材质画框、墙线强化、家具填色或必要重绘、投影、绿植、编号和图例。**置入 PDF 保持矢量清晰度，不会将其中的墙线、家具、房名自动转成 InDesign 可编辑对象。** 明确哪些是链接 PDF、哪些是原生绘制、哪些是位图材质。

精制使用选定的样式参数，同时以真实材质方向、门洞边界、家具形状和功能层级校正效果。闭合路径贴合实际边界，材质在对应画框内裁切；原图曲线需用原生曲线描绘，不能靠粗折线冒充。统一光向、阴影强弱与纹理尺度，保留门扇、柱网和重要图文可读性。二维模型投影是一种表达手法，不代表创建了三维模型。

具体原生操作、PDF 白底/透明度与导出核查见 [InDesign 制作与验收](references/indesign-production.md)。可用 [作业数据与脚本](references/job-format.md) 复用 A3 编排、闭合直线区域、纹理置入、墙线、编号和双列信息；复杂曲线、真实家具和精细材质仍需按源图在 ID 内绘制和检查。辅助脚本不负责自动识别房间，也不能把基础色块稿自动判成精稿。

## A3 文本页与编号

- 默认 **A3 横向 420 × 297 mm、非对页**。左侧主图，右侧“编号—功能空间名称”；采用左侧彩平、右侧功能清单的组织方式，原生页面宽高必须为 A3，不可仅改文件名。用户提供新的品牌模板时服从该模板，并保留右侧功能对应关系。
- 使用同一份房间清单生成图内圆形编号和右侧功能名称。每个编号仅对应一个空间，图内/图例无漏项、多项、错项；多楼层明确编号作用域。同名房间不合并成一个编号。主次空间可用深浅编号区分，但确保缩印可读。
- 编号落在对应空间的清晰位置，避开房名、门扇和主要家具；必要时用短引线指向实际空间。图例以中文为主，英文仅用源图已有或用户要求的译名。长名称自动换行，名称和说明分层，不能压缩字宽或无限缩字号。
- 建议安全边距 15–18 mm，图例占页面约四分之一，编号直径约 5–6 mm，图例正文 10–12 pt。按实际平面长宽调整，不拉伸建筑。条目过多时增加 A3 页或按楼层/区域合理分页，保持图与功能表同页可对照。
- E1 参考的右侧产品图是可选选型表达；仅在用户提供产品且要求时增加，默认仍交付右侧功能表。保留原 PDF 中红线、消防/拆改等符号的原意，不以风格色覆盖其语义。

## 交付与验证状态

选样阶段只展示预存简图和选项，不生成项目文件。选定后交付该款 `.indd`、`.idml`、A3 审阅 `.pdf`、页面预览和空间编号清单；复制所用 PDF/材质到 `Links/` 并验证链接，保留原件。若字体不可打包，记录使用字体与替代情况。

逐页检查平面与底图对齐、区域边界、文字/门洞可读性、编号对应关系、图例换行、页面尺寸与有效分辨率。检查缺链/过期链接、缺字体、文字溢出，再渲染审阅 PDF 并回看整页及细部。重新打开交付 INDD，确认保存内容和链接；自动检查通过与视觉审阅通过分别记录。

本机可用 InDesign 时优先原生脚本或宿主提供的桌面 UI：macOS 可用 osascript，Windows 可在 InDesign 脚本面板运行编译后的 run.jsx，具体见制作参考。若 ID 不可用，仍可完成源图核对和风格建议，但应明确原生制作尚未完成；不可将其它软件的截图/PDF 改后缀充作 INDD。用户要求的是 InDesign 制作，不以云端 PDF 自动转换或纯 AI 出图替代。
